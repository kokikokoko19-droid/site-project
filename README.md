# site-project

成人向け動画のアフィリエイトサイト（FANZA）の制作・運営リポジトリ。
目的は「見て回る楽しさ」「新しい発見」「自分の好みに合う作品を見つける体験」を提供するカタログ型サイトを、設計・データ・編集・運用まで作り込むこと。

## 進め方（5段階）
1. 準備：リポジトリ、FANZA API、X API、ホストとドメイン
2. 設計：情報設計、データモデル、デザインシステム、編集方針、自動文ルール
3. 基盤：API取り込み、DB、静的生成、探索UI、法務ページ、計測
4. コンテンツ：自動文とラベル、運営者執筆のハブ記事、特集
5. 公開と申請：ホスト配置、FANZA追加申請、Search Console、X自動投稿

## ディレクトリ
- `docs/` 設計文書と決定事項（正本）
- 以降のディレクトリは基盤実装時に追加する

## 運用ルール
- このリポジトリには画像・動画・作品の文章を置かない。コード、設定、設計文書のみ。
- 秘密情報（API ID、トークン）はコミットしない。`.env.example` の変数名だけを共有する。
