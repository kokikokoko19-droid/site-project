## 2. 段階ごとのタスク

### 段階 1: 土台を本番に出す（仮公開）

運営者:
1. mixhost の「アダルトレンタルサーバー」をスタンダード・1 年で契約する（税込 11,616 円。docs/00 2026-11-08）。通常のレンタルサーバーではなく、アダルト用を選ぶ。
2. cPanel で SSH を有効にし、ドメイン avmeguri.com を追加する（アドオンドメイン）。ドキュメントルートのパスとサーバーの IP アドレスを控える。
3. 配信専用の SSH 鍵を作り、公開鍵を cPanel に登録する（手順は AI が docs/07 5.2 に書く）。
4. GitHub Secrets に DEPLOY_HOST、DEPLOY_USER、DEPLOY_PORT、DEPLOY_PATH、DEPLOY_SSH_KEY、DEPLOY_CHECK_URL を登録する（値は会話に貼らない。docs/07 5.3）。
5. Cloudflare の DNS に A レコードを追加する（AI の手順どおり。ネームサーバーは変えない）。
6. AI が作る PR を GitHub でマージする（Merge ボタンを押す）。
7. 仮公開後、国内から確認する: 作品ページの「サンプル動画を再生」で公式プレーヤーが動くか（docs/01 #28）、「FANZAで見る」で年齢確認のあと商品ページに着くか（#29）、スマホで見た目が崩れていないか。

AI:
1. 母集団の規模を実測し、絞り込みの案を出す（#30）。運営者が決めたら実装し、初回の取り込みを行う。
2. 仮公開用の noindex 切替（`PUBLIC_NOINDEX=1`）。済。
3. mixhost の画面に合わせて配信手順（docs/07 5 章）を埋め、初回の手動配信を行い、DEPLOY_CHECK_URL の応答を確認する。
4. `main` への PR を作る。マージ後に日次を手動実行して、実データの取り込み・cache・配信が通ることを確認する（docs/07 3.7）。
5. 国内確認のチェックリストを運営者に渡し、結果を docs/01 に記録する。

完了条件: https://avmeguri.com が表示され（noindex）、日次更新が朝 6 時に動き、配信まで自動で通る。

### 段階 2: 中身を入れる（段階 1 と並行）

運営者（執筆。露骨な表現は使わない。リポジトリに性的に露骨な文章を入れない規則のため。作品の説明はデータ駆動の自動文に任せ、記事は「選び方」「見方」「軸の解説」を書く）:
1. トップの「運営者から」（数行。今週見たもの、気づいたこと、サイトの使い方）。
2. ガイド 3 本（`src/content/guide/`。雛形あり: このサイトの使い方、はじめての 1 本の選び方、軸の解説）。各 800〜1,500 字。
3. 特集 2 本（`src/content/feature/`。雛形あり。作品の content_id を `works` に列挙。選定理由を書く）。
4. 運営者情報（ハンドル名、連絡先 info@avmeguri.com）。
5. 取り下げ依頼の窓口（メール受付。Google フォームは任意）。
6. 利用規約・プライバシーポリシーの雛形を読んで、内容に OK を出す。

AI:
1. 各記事の構成案と書き方の注意（見出し、長さ、禁止事項、内部リンクの貼り方）を渡す。
2. 特集の候補（高評価・定番・新作のデータから）を一覧にして、選定を楽にする。
3. 入稿後の表示確認、下書きバッジと仮文の除去、法務ページの最終版。

完了条件: トップと各ページから仮文・下書き表示が消え、ガイドと特集が公開状態（draft: false）になる。

### 段階 3: 本公開と DMM 申請

運営者:
1. 公開前チェック（AI が出す）を見て、公開 GO を出す。
2. FANZA アフィリエイト管理画面「サイトURLを追加申請」で https://avmeguri.com を登録する（サイト名 AVめぐり、サイトの説明）。
3. 承認のメールが来たら、新しいアフィリエイト ID（末尾 -003 など）を GitHub Secrets の `FANZA_SITE_AFFILIATE_ID` に登録する。
4. Google Search Console にサイトを登録する（所有権の確認は DNS。手順は AI が出す）。

AI:
1. 公開前チェック: PR 表記、クレジット表記、年齢確認、sitemap と robots、OGP、404、リンク切れ検査、noindex の解除。
2. `PUBLIC_NOINDEX` を外して再ビルド・配信。
3. 承認後に `AFFILIATE_LINKS=on` へ切り替え、/go/ の移動先と埋め込み動画の ID が新しい ID になっていることを確認する（docs/07 8 章）。

完了条件: 検索に載る状態で公開され、FANZA の承認が下り、リンクがアフィリエイト ID 付きになる。

### 段階 4: X の開始

運営者:
1. X アカウント `avmeguri` を作る（メールは info@avmeguri.com。「センシティブなメディア」の設定を ON。プロフィールにサイト URL と PR 表記）。
2. X Developer に登録し、従量課金（pay-per-use）の支払い方法を設定する（上限は月 10 ドル）。
3. API Key、API Key Secret、Access Token、Access Token Secret を GitHub Secrets に登録する（docs/07 と .env.example の名前どおり）。

AI:
1. dry-run の投稿文を確認して調整し、本投稿を ON にする（日本時間 9・15・21 時、1 日 3 本、URL なしが基本）。
2. 投稿履歴と費用の見方を docs/07 に書く。

### 段階 5: 育てる（公開後の運用）

- AI: 月次レポート、出演者ページの長さ（#27）、ラベルの閾値、検索流入の改善。
