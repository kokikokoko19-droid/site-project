# 第三者レビュー D：規約順守・法務・信頼性・収益化（2026-11-15）

担当: 規約順守・法務・信頼性・収益化の設計
基準: docs/10_公式確認_DMM_API.md、CLAUDE.md の「規約上の制約」

## 1. 総評
規約表記の土台（全ページの PR 帯、既定どおりのクレジット、画像の直リンク・無加工、顔写真不使用、/go/ の sponsored nofollow、データだけで作る自動文）はよくできており、DMM 規約本文との正面からの衝突は少ない。ただし、自分たちが docs/10 で「不可」と判定した全件 JSON の公開（D-1）と、承認前なのに埋め込み動画に API 用 ID が付く点（D-2）が実装に残っている。審査の観点では、連絡先の空欄（D-3）と自作コンテンツ 0 本（D-4）が不承認の典型例に当たる。申請前に D-1〜D-4 を片付け、その次に導線（D-8）と計測（D-7）を整えれば、承認後すぐ収益化に入れる。件数: 重大 4、重要 7、改善 6。

## 2. 指摘一覧
### 重大
**D-1 公開 JSON が「全件ダンプ」になっている**
- 場所: /data/works-000〜004.json、/data/index.json（ローカル・本番とも。PC で取得）
- 現象: 4,096 件×18 項目（題名、出演者名、メーカー、シリーズ、ジャンル、収録分、配信日、レビュー件数・平均、価格、定価、セール有無、画像 URL、順位、ラベル）を誰でも一括取得できる。計約 2.4MB。robots.txt は /go/ だけ Disallow。
- なぜ問題か: docs/10 §1 判定表は「公開リポジトリ・公開ページにDB・全件データを置く＝不可」「サイトで全件ダンプのJSONを配ることも避ける」とし、根拠に規約 9条1項(8)「不特定または多数人と情報を共有することを可能にする場所に…保管すること」を挙げる。自分たちの判定と実装が食い違っている。8条5項で DMM はクロールで監視する。
- 直し方の案: (a) 探索に要る項目だけに絞る（価格・定価・レビュー件数/平均・画像 URL・順位を外し、作品ページで見せる）。(b) 新着・セールの絞り込みは静的ページ（ジャンル別の一覧）で作り、JSON の範囲を探索だけに限る。(c) /data/ を robots で Disallow し、サーバーで X-Robots-Tag: noindex。(d) DMM へ「探索用の JSON 配信」の可否を照会（docs/01 #12 の照会に同梱）。
- 影響度: 高／工数: 中

**D-2 埋め込み動画に API 用 ID が付いたまま、未承認サイトで配信している**
- 場所: 作品ページのサンプル動画（例 /v/125umd01025/）。dist 全体で 7,247 ページ
- 現象: data-src の litevideo URL に `affi_id=（会員ID）-990` が入る。/go/ は承認前の方針どおり ID なしの公式 URL なのに、動画だけ ID 付き。
- なぜ問題か: docs/07 §8「承認前のサイトにアフィリエイトリンクを置くことはできない」と矛盾。docs/10 お知らせ 2025-10-14 の非承認例「登録外サイトでのID使用」に当たり得る。docs/01 #12・#16 は未照会のまま。
- 直し方の案: AFFILIATE_LINKS=off のときは sampleMovie を出さない（または `affi_id` を除いた URL で再生できるか国内で確認して使う）。承認後に on と同時に有効化。照会結果は docs/01 に記録。
- 影響度: 高／工数: 小

**D-3 連絡先・運営者が空欄のまま（info@avmeguri.com が全ページに無い）**
- 場所: /about/（#contact は「（運営者が記入）」）、/privacy/、/removal/ は /about/ を参照するだけ
- 現象: docs/00（2026-11-03）で決めた info@avmeguri.com がサイトのどこにも無い。掲載停止・開示請求・問い合わせの窓口が実質ゼロ。
- なぜ問題か: 審査担当は運営者の実在と連絡手段を必ず見る。プライバシーポリシーの開示請求窓口と掲載停止の受付は、連絡先が無いと成立しない。仮文であることは既知だが、これは申請の前提条件。
- 直し方の案: 申請前に最低限「運営者名（屋号可）・所在地の都道府県・メールアドレス」を確定。メールは画像化せず `info＠` 表記か mailto。Cloudflare 転送は送信不可（docs/00）なので、Gmail の「別のアドレスから送信」を設定して返信できるようにする。
- 影響度: 高／工数: 小

**D-4 自作コンテンツが仮文のみで、自動生成ページが 8,585 件**
- 場所: /feature/、/guide/、トップ「運営者から」
- 現象: sitemap は 8,585 URL（作品 4,096、出演者 2,431 など）。運営者の文章は 0 本（すべて仮文）。
- なぜ問題か: docs/01 #18 が挙げる不承認例「自作コンテンツ不在」。規約 9条1項(1)「閲覧者に誤解を与えるおそれのある…内容」と合わせ、データの羅列だけのサイトと見られやすい。
- 直し方の案: 申請前に特集 2 本＋ガイド 3 本を本文 2,000 字以上で公開し、トップから 1 クリックで届くようにする。出演者ページは作品 3 件以上に限って索引に出す。
- 影響度: 高／工数: 大（運営者執筆）
### 重要
**D-5 「画像・動画はDMM.comの提供」が残っている**
- 場所: /about/「画像・動画・作品情報について」、/terms/「権利表記」
- 現象: 提供元が DMM であるかのような文言。
- なぜ問題か: docs/10 §2 末尾が 9条1項(1)「当社との提携関係を表示しまたは暗示する内容」に当たり得ると注意済み。
- 直し方の案: 「画像・動画は公式の配信元から直接表示しています（権利は各権利者に帰属）」に統一。クレジットはフッターの既定文言だけにする。
- 影響度: 中／工数: 小

**D-6 掲載停止の受付に期限と手順が無い**
- 場所: /removal/（PC・スマホ）
- 現象: 「速やかに対応します」のみ。期限、本人確認、一時非表示、DMM からの取り下げ依頼の扱いが無い。
- なぜ問題か: 出演者・権利者からの依頼は成人向けサイトで最も多い連絡。docs/10 お知らせ 2026-06-24・2026-09-07 は取り下げを求めており、config/blocklist.json の仕組みは既にある。
- 直し方の案: 「受付後 3 営業日以内に返信、内容確認中は該当ページを先に非表示、確定後 7 日以内に反映（次回の日次更新）」と明記。件名の書式（【掲載停止】URL）と必要事項を箇条書きにする。
- 影響度: 中／工数: 小

**D-7 計測が設計どおり動かない（GA4 未設置、/go/ のイベントは死んだコード）**
- 場所: 本番 / と /go/125umd01025/（gtag の読み込み無し）、src/pages/go/[id].astro
- 現象: PUBLIC_GA4_ID が未設定で、本番に gtag が無い。/go/ は Base を使わないため `window.gtag` が常に未定義で `outbound` は送られない。cta_click は `data-cta="work"` 1 種類で、ボタンの位置を区別できない。
- なぜ問題か: プライバシーポリシーは GA 使用を明記しており実態と不一致。仮公開中に基準値を取れない。月 50 万円の目標に対し、どの導線が売上に効いたかを測れない。
- 直し方の案: 仮公開中から GA4 を入れる。cta_click に `cta_pos`（top/after_gallery/sticky/modal）を付け、GA4 で主要イベントに指定。/go/ の gtag 呼び出しは削除（二重計上を避ける）。プライバシーポリシーに外部送信先（Google アナリティクス、Google Fonts、pics.dmm.co.jp、www.dmm.co.jp の動画プレーヤー）を列挙する（電気通信事業法の外部送信規律への備え）。
- 影響度: 中／工数: 小

**D-8 「FANZAで見る」が遠く、一覧からは一度も出ない**
- 場所: 作品ページ（スマホ 375×740）、トップ・/sale/
- 現象: CTA は作品ページに 1 個だけで、上端から 1,877px（約 2.5 画面下）。トップと /sale/ の /go/ リンクは 0。
- なぜ問題か: ダイレクト報酬（35%）もカテゴリ報酬（10%）も、FANZA に送らなければ発生しない（docs/10 §5 追記）。「サービス新規」2,100 円や FANZA TV 新規無料登録 2,750 円の定額報酬への導線も無い。
- 直し方の案: 作品ページは価格の直下に CTA、ギャラリー後に 2 個目、スマホは下部固定バー（「FANZAで見る PR」＋価格）。/sale/ と /new/ の各カードに小さな CTA。承認後、管理画面のリンク作成（規約第3条）で月額・FANZA TV の紹介リンクをガイド記事に置く。
- 影響度: 高／工数: 中

**D-9 本番のボット対策が審査と DMM の監視クロールを止める恐れ**
- 場所: https://avmeguri.com 全体
- 現象: 短時間に複数ページを開くと確認画面が出る（ブリーフ記載）。
- なぜ問題か: 審査担当は多くのページを素早く開く。規約 8条5項でクロールによる監視に同意しており、遮断は不利。
- 直し方の案: 申請から承認までは確認画面のしきい値を緩める、または /go/・/data/ だけに限定する。
- 影響度: 中／工数: 小

**D-10 年齢確認の文言と実装が最小限**
- 場所: 全ページの年齢確認（スマホ）
- 現象: 「成人向けの作品情報を扱います。18歳以上ですか」のみ。JS 無効時はゲートが出ず本文が見える。「18歳未満です」は about:blank。期限なしで localStorage に保存。Tab で背後の検索欄へフォーカスが抜ける。
- なぜ問題か: 審査担当や X の審査は「アダルトコンテンツを含む」「18歳未満の閲覧禁止」の明示を見る。
- 直し方の案: 文言を「アダルトコンテンツ（性的な表現を含む作品情報）を掲載しています。18歳未満の方の閲覧はお断りします」にし、利用規約・プライバシーポリシーへのリンクを添える。`<noscript>` で同じ警告と本文非表示。背後に `inert`。未満は安全な外部ページへ。保存は 30 日程度で失効。
- 影響度: 中／工数: 小

**D-11 X 投稿テンプレの規約リスク**
- 場所: src/x/compose.ts、src/lib/autotext.ts の POST
- 現象: 題名を原文のまま載せる。価格文（セール価格と通常価格）を含む文型がある。#PR とサイト内 URL は付く。
- なぜ問題か: 題名には露骨な語が多く、X では成人向け表示の設定が無いと制限される。セールは日次更新の間に終わることがあり、古い価格の投稿は誤認表示になる。DMM お知らせ 2025-11-12 の禁止事項（無関係なキーワードの羅列）への配慮は、ジャンル列挙 3 語までで概ね守れている。
- 直し方の案: アカウントの「センシティブな内容を含む」設定を必須手順に（docs/01 #24）。価格は投稿文から外し「価格はリンク先で」にする。投稿直前にカタログの生成時刻が 24 時間以内かを確認して古ければ止める。
- 影響度: 中／工数: 小
### 改善
**D-12 PR 表記の文言と見え方**
- 場所: 全ページ上部の PR 帯（スマホ 11.5px、2 行、スクロールで消える）
- 現象: 「作品リンクはPRです」で、リンク以外（紹介文・ランキング）が広告の一部だと読めない。

- 場所: 8,585 ページすべて（display:none、aria-hidden）
- 現象: ソースに「広告スロット（空）」が残る。他 ASP・広告ネットワークのタグは 0（確認済み）。

- 影響度: 低／工数: 小

## 3. 良い点
- クレジットはフッターに既定ソースのまま（`Powered by <a href="https://affiliate.dmm.com/api/">FANZA Webサービス</a>`、docs/10 §2 と一字一句一致）。/go/ 以外の全 HTML に PR 帯とクレジットがある。
- 画像は 130,690 箇所すべて pics.dmm.co.jp の直リンクで object-fit: contain（切り取り無し）。女優の顔写真（actjpgs）は 0 件。動画は公式プレーヤーの iframe をクリック後に差し込むだけ。
- /go/ の中継は noindex＋robots Disallow、リンクは rel="sponsored nofollow"。承認前は ID なしの公式 URL に切り替える仕組み（src/lib/links.ts）が環境変数だけで済む。
- 自動文（autotext.ts / autotext-actress.ts）は API 項目の組み立てだけで、商品説明やレビュー本文を使っていない。欠けた項目は句ごと省く設計も誤情報を防ぐ。
- 計測は検索語や作品名を送らず文字数だけ、GA の広告機能は無効。価格に「データ更新時点」の注意書きがある。

## 4. 運営者の要望 1〜3 への見解
- 要望 1（今週の1本をスライド）: 各スライドの画像は直リンク・contain のまま、文字や値札を画像に重ねない（D-14）。自動送りには一時停止ボタンを付ける（WCAG 2.2.2）。スライドごとに「作品ページへ」と小さな「FANZAで見る PR」を置き、`cta_pos=hero` で計測する。
- 要望 2（探索の「重み」）: 規約面では、並び順の根拠を画面に一文で示すと信頼性が上がる（例「評価・レビュー数・新しさから当サイトが計算。広告費による順位付けはありません」）。
- 要望 3（新着の絞り込み）: 新着の全件を JSON で配ると D-1 が悪化する。ジャンル別の新着一覧を静的ページで生成し、チップはそのページへのリンクにする方式を勧める。

## 5. DMM 審査（サイト URL 追加申請）前チェックリスト
申請前に、すべて「はい」にする。
1. 運営者名・連絡先（info@avmeguri.com）を /about/ に掲載し、返信できる状態か（D-3）
2. 利用規約・プライバシーポリシー・掲載停止の雛形表示が消え、制定日・期限が入っているか（D-6）
3. 自作の記事 5 本以上（各 2,000 字以上）がトップから辿れるか（D-4）
4. アフィリエイト ID が HTML に 1 つも無いか（`grep -r "af_id\|affi_id" dist` が 0、D-2）
5. 公開 JSON を最小化し /data/ を Disallow したか（D-1）
6. 全ページに PR 表記、フッターに既定クレジットがあるか（済）
7. 提携を暗示する文言（「DMM.comの提供」）を消したか（D-5）
8. 他 ASP・広告タグが無いか（済、0 件）
9. 年齢確認の文言が明確か（D-10）
10. 本公開（noindex 解除）済みで、ボット対策が審査を止めないか（D-9）
11. 申請はアダルト区分・サイト URL は https://avmeguri.com（www なし）で、サブドメインを使っていないか（お知らせ 2025-10-14、2022-08-24）
