暗い漆色の地、紙色の文字、明朝の見出し、朱の印という方向は良く、箱で囲まない棚や索引など「専門カタログ」の骨格はできている。ただし 5 秒見ると、(1) 公式の小さい表紙（147×200px）を 1.5〜3.9 倍に引き伸ばしたぼやけた画像、(2) 全セクションが「明朝の見出し＋灰色の仕組み説明＋もっと見る →」の同じ型で並ぶ単調さ、(3) 自動文を「」で飾って人の声に見せる演出、の 3 点が「AI 製テンプレ」の印象を作っている。公開前の最優先は、画像を原寸以下で見せる配置への作り直し、セール一覧の価格表示、スマホ作品ページの購入ボタン位置、favicon と OGP 画像の用意。

## 2. 指摘一覧
### 重大

**B-1 一覧画像を原寸以上に引き伸ばしていて、ぼやけて安っぽく見える**
- 場所: /actress/1088602/ の「おすすめ作品10選」（PC・スマホ）、/new/ /ranking/ /sale/ の格子（PC）、探索・トップの棚
- 現象: カードの表紙は公式の一覧用画像（147×200px）。表示幅は出演者ページ PC 568px（3.86 倍）、スマホ 358px（2.44 倍）、一覧 PC 221px（1.5 倍）、スマホ 171px（1.16 倍）。高解像度の画面ではさらに 2 倍になる。
- なぜ問題か: 画像が主役のカタログで、ぼやけた表紙は「手間をかけていないサイト」の最も強い信号。加工は拡大縮小のみ可だが、縦長の大きい画像は配信されていない。
- 直し方の案: 縦長表紙は最大 160px 幅までの部品と決める（トークン `--cover-w: 148px`）。格子は `grid-template-columns: repeat(auto-fill, minmax(132px, 160px))` にして PC は 7 列、余白は列間で吸収。出演者ページの 10 選は「左に表紙 148px、右に順位・題名・理由」の横長行にする（`.rank-item { grid-template-columns: 148px minmax(0,1fr) }`）。大きく見せたい場所は横長ジャケット（800px 級）だけを使う。
- 影響度: 高／工数: 中

**B-2 セール一覧に価格も割引も出ていない**
- 場所: /sale/（スマホ・PC）
- 現象: トップの棚には値札が 10 枚出るが、/sale/ の格子は 0 枚。カードの表示条件が `variant === 'shelf' && tag` のため、格子では値札も価格も出ない。カードに出るのは「セール中」という文字ラベルだけ。
- なぜ問題か: セール一覧の目的は値段の比較。見比べられないと作品ページに入る動機が無い。
- 直し方の案: 格子カードの題名の下に価格行を足す（`.price` のセール価格＋取り消し線の定価＋割引率「-30%」）。値札は表紙の上ではなく本文側に置く（B-15）。/sale/ は割引率順と終了日の並べ替えも欲しい。
- 影響度: 高／工数: 小

**B-3 スマホの作品ページで購入ボタンが 2 画面下にある**
- 場所: /v/mdvr00447/ ほか（スマホ）
- 現象: `.cta-box` の上端が 1,549〜1,690px（画面の高さ 844px）。題名、表紙、サンプル画像 12 枚の格子のあとにある。
- なぜ問題か: 売上に直結する唯一の出口が、スクロールしないと見えない。
- 直し方の案: スマホは並び順を「題名→表紙→価格と FANZA ボタン→自動文→仕様→サンプル」に変える（`.detail` の `order` で可能）。さらにスクロール後は画面下に固定の細い帯（価格＋「FANZAで見る PR」、高さ 56px、`position: sticky; bottom: 0`、`--bg1` に上罫線）を出す。
- 影響度: 高／工数: 小

**B-4 favicon と OGP 画像が無い**
- 場所: 全ページ（本番 https://avmeguri.com/favicon.ico も 404）
- 現象: `<link rel="icon">` が無く、`og:image` を渡すページが 1 つも無い。`twitter:card` は summary_large_image を宣言しているのに画像が無い。
- なぜ問題か: X 投稿が集客の柱なのに、カードが無地になる。タブとブックマークで印が見えない。
- 直し方の案: 印「巡」を文字ではなく線に変換した `favicon.svg`（文字は Web フォントに頼らない）と 180px の `apple-touch-icon.png` を用意。OGP は 1200×630 の固定画像（漆色の地、朱の印、明朝の「AVめぐり」と一行の説明）。作品画像は入れない（露骨さと規約上の加工を避ける）。特集・出演者ページは同じ型に題名だけ差し込んだ画像をビルド時に生成。
- 影響度: 高／工数: 小
### 重要

**B-5 全セクションが同じ型で、説明文が「仕組みの説明」になっている**
- 場所: トップ（スマホ・PC）、探索、作品ページ
- 現象: 5 つの見出しがすべて「明朝 22px＋灰色の補足＋右端の『もっと見る →』」。補足は「評価と定番から選んだ作品」「運営者が選び、運営者が書く」「並べ替えの重みと絞り込みはURLに残ります」「タグの重なりと同出演者・同シリーズで自動選定」など、作り手の仕組みを説明する文。間隔も全セクション 56px で同じ。
- なぜ問題か: 均一な繰り返しと仕組みの説明は、テンプレ生成の典型的な印象。読者の得になる言葉になっていない。
- 直し方の案: 補足は原則削除し、残すなら読者向けの言葉にする（例「今月の配信から」「〇日まで」）。見出しに大小を付ける: 目玉と今日の発見は大（28px）、索引・特集は中（22px）、新着とセールの棚は小（17px＋件数）。セクション間隔を `--gap-l: 80px` と `--gap-s: 40px` の 2 種にし、索引の前後だけ広く取る。
- 影響度: 高／工数: 小

**B-6 自動文に「」の引用装飾を付けて、人の声のように見せている**
- 場所: トップのヒーロー、作品ページ、出演者ページ（スマホ・PC）
- 現象: `.lead::before` が大きな「を左上に置く。トップでは中身が「メーカー・分数・件数」の羅列で、下の情報行と重複。スマホでは「が行の外にはみ出して、欠けた記号に見える。
- なぜ問題か: 引用符は誰かの言葉の印。データからの自動文に付けると、運営者の声と区別が付かず、気付いた読者には「AIが書いた文を人の声に見せている」と映る。
- 直し方の案: `.lead` の明朝と引用符をやめ、本文ゴシック 15px・`--fg1` の普通の段落にする。明朝と「」は運営者が書いた文（`.letter` `.editorial`）だけに使うと決める。ヒーローの自動文が情報行と重なるときは出さない。
- 影響度: 中／工数: 小

**B-7 「運営者が選ぶ」と書いた目玉が、実際は自動選定**
- 場所: トップのヒーロー
- 現象: 見出しの上に「今週の1本　運営者が選ぶ」。実装は「高評価」ラベルの先頭を自動で選ぶ。
- なぜ問題か: 人の手を装う表記は信頼を落とす。B-6 と同じ。
- 直し方の案: 運営者が content ID を指定するまでは「今週の高評価」と書く。指定の仕組みは要望 1 の案（4 章）で作る。
- 影響度: 中／工数: 小

**B-8 文字サイズが 15 段階あり、強弱がぼやけている**
- 場所: トップ（PC）
- 現象: 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 15.5 / 16 / 17 / 18 / 21 / 22 / 24 / 34px。0.5px 刻みの差は目で区別できない。
- 直し方の案: トークンを 7 段階に絞る: `--fs-xs: 11px`（ラベル）、`--fs-s: 12.5px`（補足）、`--fs-b: 15px`（本文）、`--fs-m: 17px`（カード題名・小見出し）、`--fs-h3: 20px`、`--fs-h2: 26px`、`--fs-h1: clamp(26px, 3vw, 36px)`。行間は本文 1.8、見出し 1.4、カード題名 1.5。英数字が多い題名は `font-feature-settings: "palt"` を見出しに付けて詰める。
- 影響度: 中／工数: 中

**B-9 スマホで見出しや数字が不自然に折り返す**
- 場所: トップ、/ranking/actress/、出演者ページ（スマホ・PC）
- 現象: 「今日の発見」「特集とガイド」の見出しが 2 行に割れる（高さ 59px。補足ともっと見るに幅を取られる）。索引の件数が「31作／品」と 3 行に割れる。出演者ランキング表の「48／件」「順／位」。出演者ページの h1 が語の途中（「おすす／め」）で改行。
- 直し方の案: `.section-head h2 { flex: none; }`、スマホは補足を見出しの下の行へ（`flex-wrap: wrap`、補足に `flex-basis: 100%`）。件数・順位・数値列は `white-space: nowrap`。見出しに `word-break: auto-phrase`（Chrome 119+、効かない環境は従来どおり）。
- 影響度: 中／工数: 小

**B-10 今日の発見の項目の高さが倍以上ばらつく**
- 場所: トップ（スマホ）
- 現象: 3 項目の高さが 198 / 395 / 221px。題名と出演者名に行数の制限が無く、長い作品で 8 行を超える。

- 影響度: 中／工数: 小

**B-11 ヒーローの比率と題名の大きさが表紙に合っていない**
- 場所: トップ（PC・スマホ）
- 現象: 表紙は 800×600（4:3）なのに枠は 3:2 固定で、左右に地色の帯が出る（作品により 800×538 もある）。長い題名を最大 34px の明朝で 6 行組み、右半分が文字の壁になる。ページ最上部の h1 は、ヘッダーのタグラインと同じ文を小さく繰り返している。

- 影響度: 中／工数: 小

**B-12 朱のセール価格と、ボタン・チップの枠線のコントラストが足りない**
- 場所: 全体
- 現象: `--seal`（#c9392b）の文字は `--bg0` 上で 3.67:1、`--bg1` 上で 3.44:1（AA の 4.5:1 未満）。2 番手ボタンとチップの枠線 `--line-strong` は 1.80:1（部品の境界は 3:1 必要）。主要な文字は良好（`--fg0` 15.3、`--fg1` 8.7、`--fg2` 5.4、`--accent` 8.4、CTA の文字 8.1、値札の白 4.7）。
- 直し方の案: 文字用の朱を別トークンに分ける（`--seal-text: #e8604f` で約 5:1）。印と値札の地は今の朱のまま。2 番手ボタンの枠線は `--fg2`（5.4:1）に上げるか、`--bg2` の塗りで形を示す。目立ちの順序は「CTA（琥珀の塗り）＞値札（朱の塗り）＞2 番手ボタン（枠）＞ラベル（文字）」に統一。
- 影響度: 中／工数: 小

**B-13 ランキングに順位が出ない／出演者ランキングが表計算の表**

- 影響度: 中／工数: 中

## 5. 確認方法
- 撮影: Playwright（Chromium）で 390×844 と 1280×800、`localStorage.age_ok=1` を初期化スクリプトで入れて年齢確認を飛ばし、/、/explore/（カードを1枚押してモーダル）、/new/、/sale/、/ranking/、/ranking/actress/、/v/mdvr00447/、/actress/1088602/、/about/、/privacy/、/404.html を、最初の画面と全体で撮影。年齢確認は保存なしの新しいコンテキストで撮影。
- 画像の拡大率: `main img` ごとに `getBoundingClientRect().width / naturalWidth` の最大値と 1.05 を超える枚数を集計。
- 見出しの折り返し: `.section-head h2` の高さ（1 行 30px、2 行 59px）。今日の発見の各項目の高さ。
- 文字サイズの段階: 文字を直接持つ要素の `getComputedStyle().fontSize` の重複なし一覧。
- 購入ボタンの位置: `.cta-box` の `getBoundingClientRect().top`（スクロール 0 の時点）。
- 価格の有無: `curl -s http://127.0.0.1:8787/sale/ | grep -c 'class="tag"'`（トップは 10、/sale/ は 0）。
- コントラスト: tokens.css の色を WCAG 2.x の相対輝度式で計算（背景はノイズと放射グラデを無視した `--bg0`）。
- favicon: `curl -o /dev/null -w '%{http_code}' https://avmeguri.com/favicon.ico` → 404。`og:image` は全ページで出力なし（`ogImage` を渡すページが無い）。
