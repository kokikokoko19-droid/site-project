## 5. 確認方法
- 撮影: Playwright（Chromium）で 390×844 と 1280×800、`localStorage.age_ok=1` を初期化スクリプトで入れて年齢確認を飛ばし、/、/explore/（カードを1枚押してモーダル）、/new/、/sale/、/ranking/、/ranking/actress/、/v/mdvr00447/、/actress/1088602/、/about/、/privacy/、/404.html を、最初の画面と全体で撮影。年齢確認は保存なしの新しいコンテキストで撮影。
- 画像の拡大率: `main img` ごとに `getBoundingClientRect().width / naturalWidth` の最大値と 1.05 を超える枚数を集計。
- 見出しの折り返し: `.section-head h2` の高さ（1 行 30px、2 行 59px）。今日の発見の各項目の高さ。
- 文字サイズの段階: 文字を直接持つ要素の `getComputedStyle().fontSize` の重複なし一覧。
- 購入ボタンの位置: `.cta-box` の `getBoundingClientRect().top`（スクロール 0 の時点）。
- 価格の有無: `curl -s http://127.0.0.1:8787/sale/ | grep -c 'class="tag"'`（トップは 10、/sale/ は 0）。
- コントラスト: tokens.css の色を WCAG 2.x の相対輝度式で計算（背景はノイズと放射グラデを無視した `--bg0`）。
- favicon: `curl -o /dev/null -w '%{http_code}' https://avmeguri.com/favicon.ico` → 404。`og:image` は全ページで出力なし（`ogImage` を渡すページが無い）。
