# 技術調査: 公式の動画埋め込みツール（無料動画ツール／litevideo）

調査日: 2026-11-01。公式ページ（affiliate.dmm.com/guide/diagram/blogparts/litevideo/）は地域制限で未読。第三者の公開コードと技術記事から復元。**公式で要確認**。

## 結論
- URL は固定テンプレートで、content_id（cid）から組み立て自体は可能。ただし公式は「無料動画ツール（共有ボタン）の提供方法以外は動作保証外」としている。
- API の `sampleMovieURL` は mp4 ではなく、この公式プレーヤーの URL を返す。**API の値をそのまま iframe で使う方式を第一とし、手組みは補助に留める。**

## 1. 埋め込みコードの形式（一致）
`https://www.dmm.co.jp/litevideo/-/part/=/affi_id={アフィリエイトID}/cid={cid}/size={幅}_{高}/`
- size の実例: 1280_720（共有コードで主流）、720_480、644_414、560_360、476_306。
- パラメータの順序は不問の実例あり。
- 共有ボタンの出力は、上記 URL を `padding-top:75%` のレスポンシブな div と iframe で包んだ形とみられる（単一資料）。

## 2. API の sampleMovieURL との関係
- `size_476_306` 〜 `size_720_480` の4種と `pc_flag`/`sp_flag`（PC/スマホ対応の0/1）。
- affiliate_id 付きで要求すると `affi_id=<API用ID>` が付く。**公開時にリンク用IDへ差し替えてよいかは要確認。**
- cid は通常 content_id と同じだが、異なる実例あり（例: 商品ページの cid と litevideo の cid の表記違い）。sampleMovieURL 自体が無い作品もある。

## 3. 制約
- 自動再生の記述なし（クリック再生前提と推定）。
- スマホ閲覧時の挙動は公式記述なし。はみ出し対策の CSS 記事あり。
- Cookie なしの取得では年齢認証ページが返った。ブラウザ内 iframe での挙動は未確認。
- 複数設置、loading="lazy"、sandbox 付きの稼働例はあるが公式記述なし。

## 4. 規約面の注意（公式ヘルプ）
- 提供方法以外の掲載は動作保証外（S47545）。動画共有サイトへのリンクは禁止（S47539）。
- 共有ボタンのタグは X では使えない。X 向けは DMM 提供の使用可能なサンプル動画を案内。
- mp4 の直リンクは明記なし。推測 URL は旧形式で、新形式は一時トークン付きのため不安定。採用しない。

## 5. 公式で要確認
1. API 値・cid からの手組みが「提供方法」に当たるか。
2. affi_id に API用ID を使ってよいか、サイト用IDに替えるか、計測・報酬への影響。
3. size の許容値、autoplay / mute の有無。
4. 年齢認証と第三者 Cookie 制限下での表示、sp_flag=0 の扱い。
5. lazy・複数設置・sandbox の可否。
