調査日: 2026-10-23。公開ページの GET 取得のみ。作品内容には触れず、構造・機能・運用の事実だけを記録する。数字は取得時点のもの。

## 1. oppaisan.com（記事 /archive/8214/ とサイト全体）

### 記事8214の型
- タイトルは「[ASP名]おすすめランキング！[年]年買うべき[訴求語]傑作[数]本を更に[軸]別で紹介！」の毎年更新前提のピラー型。公開2019-02、表示更新2024-01。一覧の最新作は2023-08で、約2.8年未更新。
- h1×1、h2×2（軸別TOP5／作品一覧）、h3×8、目次あり。可視の静的テキストは約1,300字。
- 本体は 280件の data 属性付き li を JS で並べ替え・絞り込み・モーダル表示する対話型一覧。軸別TOP5×8は同じ280件から「(評価+件数+価格+新しさ)×キーワード一致数」で再抽出。重要度スライダー4本と上位20タグの AND 絞り込み。
- 1作品: サムネ1枚、モーダルにパッケージ大1、サンプル画像0〜20枚、サンプル動画 mp4×1（直リンク）、購入者レビュー引用（平均約250字）、紹介文（31件のみ）、スペック表。**レビュー引用と mp4 直リンクは本プロジェクトでは採用しない（規約）。**
- 購入ボタンはモーダル内2個を全作品で共用し、クリック時に JS で cid を差し替え。リンクは `exad.jp/link.php?i=..&m=..&pageid=<DMM詳細URL>`（ASP「イークスアフィリ」経由）。
- 画像・動画は pics.dmm.co.jp / cc3001.dmm.co.jp の直リンク。本文内の内部リンクは目次のみ。関連18・新着34・PV10 は自動枠。

### サイト全体
- WordPress。テーマ rwd_op、Contact Form 7、Google XML Sitemaps、広告枠管理プラグイン。Cloudflare、GTM＋GA4、回遊履歴を Google フォームへ送る自前 JS。
- 記事数 11,546。新規は2026年3〜6月に月90〜120件、7月38→8月31→9月9→10月0 と失速。10月は旧記事のリライト中心。
- 分類は WP タグ421個をカテゴリ代わりに使用（サイズ別16段階、形状別8種、人物、媒体、シチュエーション等の属性軸）。検索は WP 標準のみ。週間人気ランキング50件、サイドバー PV10。
- 収益は二系統。画像まとめ記事は広告4社の PC 向け7枠。作品紹介系は広告非表示（body class `not_ad`）で FANZA（exad.jp）と MGS（ad-nex.com）。作品紹介タグの記事は77本＝全体の約0.7%。
- 年齢確認ゲートなし（フッター注意書きのみ）。about / profile / privacypolicy / aggrement / mailform / 相互リンクあり。SNS は X 1アカウントのみ。

### 読者利用の推定
軸別TOP5で即決、またはスライダーとタグで280件を並べ替えて比較し、サンプルを試視聴して FANZA へ。本文に他記事リンクがなく、回遊よりページ内完結で購入へ誘導する設計。

## 2. hitozuma-fans.com と運営者の note

### 前提
FANZA ではなく **myfans**（クリエイター課金サービス）のアフィリエイトサイト。FANZA/DMM の痕跡なし。

### 運営者の自己申告（note、2026-10-14公開、全文無料、根拠画像なし）
- ツール: ChatGPT・Claude Code（月2万円）・Gemini を契約し、運営に使うのは Claude Code のみ。「サイト作り・データ集め・X運用をほぼ任せる」。記事生成・画像処理の言及なし。
- 本人の作業は方針決定と最終確認で1日約1時間。構築は「決めた翌日に公開」。
- 経過: 9/25 公開 → 10/5 アフィリエイト承認 → 10/7 初報酬 → 10/11 に7日間で12件。別記事: 2週累計19件・見込み報酬20,136円・クリック2,601、週PV3,893、流入は X＞Google＞Yahoo。
- 過去の副業は全て成果ゼロ。2週目に「クリック増・成約減」を報告。
- 他記事8本（無料5・有料3。有料は480〜3,980円）。

### サイトの構造
- Astro 製の静的サイト。素の JS、Cloudflare 配信、Workers+D1 の自前計測、Workers AI+Vectorize の検索（JS コメントより）。
- ナビ: 人気・セール・新着・ガチャ・本人提供動画・ジャンル別リール・姉妹サイト。フッター: まとめ／運営概要／規約／プライバシー／掲載停止依頼。軸はジャンルタグ19、価格/セール、長さ、期間別ランキング、クリエイター、月額プラン。
- 規模・更新: sitemap 9,487 URL（多言語込み。日本語2,402＝個別動画2,171・クリエイター151・まとめ18・特集11ほか）。lastmod の81.5%が当日。フッターにデータ更新日時。新着は1日8〜19本、作品DB約4,720本。
- 個別ページ: H1 は X 投稿文そのまま、価格・長さ・CTA「フル動画を見る(PR)」・月額プラン誘導・元 X 投稿リンク・タグ・同クリエイター8本＋同ジャンル5本・JSON-LD。本文約1,800字。
- まとめ記事: 10クリエイター×作品4本で約9,800字。テンプレ文＋指標表、順位は自動算出と明記。
- 画像・動画: サムネは myfans の CDN と X の CDN、動画は X の mp4 を直リンク。本人提供動画のみ自前配信。
- 検索等: AI 検索、タグ、並び替え、縦スワイプのリール。
- アフィリエイトリンク: 全 CTA が内部 `/go/{UUID}`（rel=sponsored）で、JS が流入元・キャンペーン・設置場所・訪問IDを付与。
- 年齢確認: JS オーバーレイあり。第三者広告タグなし。PR 表記はヘッダー・各 CTA・フッター・規約。運営者名・住所の記載なし。問い合わせは Google フォーム。

### 主張と実態の整合
- 「AI に任せて毎日自動」は整合（日次再生成、Astro+Workers 構成）。ただし「AI が記事を書く」型ではなく、DB＋テンプレ自動生成。
- 「許可者のみ画像・動画」は整合（許可119人の記載）。一方、フッターの「動画は保存・配信しない」は自前配信83本に触れず不正確。

## 3. 本プロジェクトへの示唆
- 探索 UI は 8214 型（重み付け並べ替え＋タグ絞り込み＋サンプル確認）を採用。レビュー引用と動画直リンクは置き換える。
- 運用は hitozuma 型（静的生成、毎日自動更新、X 自動投稿、内部リンク経由の計測）。
- 両サイトとも作品ごとの文章は AI 生成ではなく、データ＋テンプレ、または X 投稿文の転載。
- 参考サイトの収益・時間は自己申告で未検証。計画の前提に使わない。
