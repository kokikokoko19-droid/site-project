# 画面モック（設計方針 v1 のレビュー用）

ブラウザで直接開けます。外部通信はしません。データは合成（作品 0001〜0300、出演者A〜T、タグ01〜20）で、露骨な語は含みません。

| ファイル | 内容 |
|---|---|
| `top.html` | トップ。運営者のひとこと、今日の発見、軸の入口、特集とガイド、新着、セール |
| `explorer.html` | 探索。5つの重みスライダー、ジャンルのAND絞り込み、出演者・シリーズ・メーカー、価格・長さ・年、条件とラベル、検索、ランダム。状態はURLに残る |
| `work.html?id=w0008` | 作品ページ。自動文、仕様、サンプル枠、CTA（PR）、軸への横移動、似た作品 |
| `data.js` `ui.js` `explorer.js` | 合成データ、共通部品、探索の処理 |
| `tokens.css` `common.css` | デザイントークンと共通スタイル |

初回は年齢確認が出ます。「18歳以上です」を押すと端末に保存されます。広告スロットは空のまま非表示です（`<body class="show-ad-slots">` で枠を表示できます）。

## 運営者に判断してほしいこと（設計方針12章）
1. 対象作品の範囲: 直近36か月＋指定軸の全作品（約1万件）で始めてよいか。
2. デザインの方向性: この暗めの落ち着いた配色と余白の取り方でよいか。参考にしたいサイトがあれば。
3. 探索UIの使い勝手: スライダーとチップの操作はスマホで扱えるか。モーダルと作品ページの役割分担はこれでよいか。
4. X投稿の本数と費用の上限（1日3〜5本、URLなし基本）。
5. 運営者情報の公開範囲（ハンドルネームと連絡先のみ、の案）。
6. ホストの選定（mixhost か シン・レンタルサーバー）と、外部LLMの差し込み口を今の段階で用意するか。
